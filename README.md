# نظام إدارة الكافيه (Cafe Management System)

نظام إدارة محلي لكافيه واحد، يعمل على الشبكة الداخلية بدون الحاجة لسيرفر خارجي أو قواعد بيانات سحابية.

## التقنيات

- **Backend:** Node.js + Express.js
- **Frontend:** HTML, CSS, JavaScript (بدون إطار عمل)
- **التخزين:** ملفات JSON محلية (`backend/data/`)
- **الوقت الفعلي:** Socket.io لعرض الطلبات مباشرة عند الكاشير

## التثبيت والتشغيل

1. تثبيت الحزم:
   ```bash
   cd backend
   npm install
   ```

2. تشغيل الخادم:
   ```bash
   npm start
   ```

3. فتح المتصفح على: **http://localhost:3000**

## التشغيل على الشبكة المحلية (LAN)

النظام مُعدّ للعمل على شبكة الكافيه الداخلية بحيث يعمل من عدة أجهزة في نفس الوقت.

- **جهاز واحد** يشغّل الخادم (يفضل جهاز ثابت أو كمبيوتر الكاشير).
- **باقي الأجهزة** (كاشير، كابتن، أدمن، مطبخ) تتصل بنفس الشبكة وتفتح الرابط الخاص بكل واجهة.

### لماذا يتغير عنوان الـ IP؟ (مثلاً من 192.168.0.188 إلى 192.168.0.191)

السبب **ليس من برنامج النظام**، بل من إعدادات الشبكة في ويندوز أو الراوتر:

- جهازك يحصل على الـ IP تلقائياً من الراوتر عبر **DHCP** (عنوان ديناميكي).
- كلما أعدت تشغيل الجهاز أو الراوتر، أو انقطع الاتصال ثم عاد، قد يعطيك الراوتر **عنواناً مختلفاً** (مثلاً 192.168.0.191 بدلاً من 192.168.0.188).
- لذلك الرابط (مثل `http://192.168.0.188:3000/admin`) يتوقف عن العمل ويصبح عليك استخدام الـ IP الجديد.

**الحل:** تثبيت **IP ثابت** لجهاز السيرفر حتى يبقى الرابط نفسه دائماً (مثلاً 192.168.0.188).  
→ **دليل مفصل:** [docs/SETUP-LAN.md](docs/SETUP-LAN.md) — قسم «أولاً — تثبيت عنوان IP ثابت للسيرفر».

**ملخص سريع (من ويندوز):**
1. إعدادات الشبكة → Wi‑Fi أو Ethernet → خصائص الاتصال.
2. **Internet Protocol Version 4 (TCP/IPv4)** → خصائص.
3. اختيار **Use the following IP address** وتعيين مثلاً:
   - IP: `192.168.0.188`
   - Subnet mask: `255.255.255.0`
   - Default gateway: عنوان الراوتر (غالباً `192.168.0.1`).
4. حفظ. بعدها يبقى هذا الـ IP ثابتاً ويمكنك استخدام `http://192.168.0.188:3000/admin` دائماً.

### خطوات التشغيل على الشبكة

1. على جهاز السيرفر: تشغيل `npm start` من مجلد `backend` (كما في التثبيت أعلاه).
2. عند التشغيل يظهر في الطرفية عنوان **IP الشبكة** (مثل `192.168.1.10`) وروابط كل واجهة.
3. على أي جهاز آخر متصل بنفس الـ Wi‑Fi/الشبكة، افتح المتصفح واكتب (مع استبدال `IP` بالعنوان الظاهر عندك):

| الجهاز | الرابط المباشر |
|--------|-----------------|
| **أدمن** | `http://IP:3000/admin` |
| **كاشير** | `http://IP:3000/cashier` |
| **كابتن** | `http://IP:3000/captain` |
| **مطبخ** | `http://IP:3000/kitchen` |
| **الصفحة الرئيسية** | `http://IP:3000/` |

مثال: إذا كان IP الجهاز `192.168.1.10`، واجهة الكاشير تكون:  
`http://192.168.1.10:3000/cashier`

- لا حاجة لإنترنت خارجي؛ النظام يعمل بالكامل على الشبكة المحلية.
- كل جهاز يفتح واجهته فقط؛ لا تعارض بين الأجهزة.

### معرفة IP الجهاز (إن لم يظهر عند التشغيل)

في الطرفية على جهاز السيرفر: `ipconfig` ثم ابحث عن **IPv4 Address** تحت اتصال الـ Wi‑Fi أو Ethernet.

### التسليم والتشغيل الدائم

لإعداد النظام للتشغيل الفعلي داخل الكافيه (IP ثابت، تشغيل تلقائي مع ويندوز، اختبار متعدد الأجهزة، اتصال لحظي):

- **دليل كامل:** [docs/SETUP-LAN.md](docs/SETUP-LAN.md)

| الملف | الوظيفة |
|-------|---------|
| `start.bat` | تشغيل السيرفر يدوياً |
| `install-startup.bat` | تثبيت التشغيل التلقائي مع ويندوز |
| `uninstall-startup.bat` | إلغاء التشغيل التلقائي |
| `stop-server.bat` | إيقاف السيرفر |

## الواجهات

| الواجهة | المسار | الوظيفة |
|--------|--------|---------|
| الرئيسية | `/` | اختيار دور الدخول |
| الأدمن | `/admin` أو `/admin/` | إدارة المنيو (إضافة، تعديل، حذف، صور، مكونات) |
| الكاشير | `/cashier` أو `/cashier/` | الطاولات، الفواتير، إغلاق الفاتورة |
| الكابتن | `/captain` أو `/captain/` | الطلبات للطاولات مع ملاحظات، تأكيد الطلب |
| المطبخ | `/kitchen` أو `/kitchen/` | عرض وتجهيز الطلبات |

## API

- `GET/POST/PUT/DELETE /api/menu` — CRUD للمنيو
- `POST /api/upload` — رفع صورة (لعنصر المنيو)
- `GET /api/orders/tables` — قائمة الطاولات
- `GET /api/orders/table/:tableId` — طلبات طاولة (غير المغلقة)
- `POST /api/orders` — إنشاء طلب لطاولة
- `POST /api/orders/:orderId/close` — إغلاق فاتورة

## ملاحظات

- الطلبات تُخزّن محلياً وتُربط برقم الطاولة.
- أي تعديل على المنيو من الأدمن ينعكس فوراً على واجهتي الكابتن والزبائن.
- إغلاق الفاتورة من الكاشير يغلق الطلب ولا يظهر في الطلبات المفتوحة.
- يمكن لاحقاً إضافة صلاحيات (Admin / Cashier / Captain) وتقارير يومية.
